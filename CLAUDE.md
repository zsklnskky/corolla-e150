# corolla-e150

Статический сайт без сборщика: index.html + style.css + app.js + data.js (генерится `python build.py` из data/*.json).
Выложен на GitHub Pages: репо zsklnskky/corolla-e150, ветка main, корень. Деплой = commit + push.
Правила: RU и EN в каждом тексте (`<t-ru>/<t-en>` в разметке, `{ru,en}` в данных), без длинных тире, суммы в BYN.
Новая деталь: фигура с `class="part"` и `data-id` в SVG + строка в `RAW` в app.js (lod2 = видна только на сильном зуме).
