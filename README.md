# Моя Corolla E150

Интерактивный разбор Toyota Corolla E150 (2008, 1ZR-FE 1.6, робот MMT C50A) для человека, который не разбирается в машинах.

Сайт: https://zsklnskky.github.io/corolla-e150/

- **Машина** - 3D-модель (Three.js, собрана кодом по реальным размерам: 4540 x 1760 x 1470, база 2600). Крутится мышью или пальцем, видно днище. Рентген, разбор на детали, режим «Завести» (свет и колёса), виды 3/4, бок, перед, зад, сверху, днище. Наведение - название и цена, клик - панель с данными: лампы и цоколи, номера деталей, крепёж, как снять, совместимость, цены в BYN.
- **Справочник** - колёса и шины (что встанет, вылет, разболтовка, диски с других машин), тормоза и апгрейд, все лампы с цоколями, MMT с кодами ошибок и калибровкой, форсунки, фильтры, свечи, моменты затяжки, где что находится.
- **Как едет**, **Двигатель** (анимация 4 тактов), **Робот MMT** (анимация сцепления и передач), **Салон и свет** (все лампы), **Размеры**, **Ништяки**, **Обслуживание**.
- RU / EN переключатель.

## Как обновить цены

Правишь `data/*.json` (prices, specs, deep_lights, deep_wheels, deep_drive), потом `python build.py` (пересобирает `data.js`), коммит, пуш.
Описания деталей - в `app.js` (массив `RAW`), 3D-модель - `car3d.js` (кузов по сечениям в мм, внутренности примитивами), блоки данных по деталям - `deep.js`.

Цены собраны 19.10.2026: реальные с catalog.onliner.by помечены «цена из магазина», остальное - оценка рынка Минска.
