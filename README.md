# Моя Corolla E150

Интерактивный разбор Toyota Corolla E150 (2008, 1ZR-FE 1.6, робот MMT C50A) для человека, который не разбирается в машинах.

Сайт: https://zsklnskky.github.io/corolla-e150/

- **Машина** - рисунок, который можно приближать (колёсико, щипок, кнопки). При зуме кузов становится прозрачным, на сильном зуме видны мелкие детали. Наведение - название и цена, клик - панель: что делает, цена в BYN, где купить в Беларуси.
- **Как едет**, **Двигатель** (анимация 4 тактов), **Робот MMT** (анимация сцепления и передач), **Салон и свет** (все лампы), **Размеры**, **Ништяки**, **Обслуживание**.
- RU / EN переключатель.

## Как обновить цены

Правишь `data/prices.json` или `data/specs.json`, потом `python build.py` (пересобирает `data.js`), коммит, пуш.
Описания деталей и их места на рисунке - в `app.js` (массив `RAW`) и `index.html` (`data-id`).

Цены собраны 19.10.2026: реальные с catalog.onliner.by помечены «цена из магазина», остальное - оценка рынка Минска.
